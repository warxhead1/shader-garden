Attribute reference

AttributeDefaultMeaning
kernel—Admitted kernel id. Resolves to <garden>/<id>.json. Wins priority over src/href if more than one is set.
src—Inline GLSL mainImage text. Ignored unless unsafe is present — un-admitted source is forced-click, never autoplays.
href—A garden share URL (#/edit?src=<b64url>&lang=glsl). Same unsafe requirement as src.
unsafeabsentExplicit acknowledgment that src/href is un-admitted source. Deliberately ugly to type.
gardenimport.meta.url's directoryBase URL for kernel JSON + attribution deep links. Only needed if you've copied the seed script somewhere that isn't next to its JSON.
autoplayvisiblevisible: plays while on-screen. click: poster until a gesture. off: poster; only play() starts it. Reduced-motion and low battery both degrade toward click behavior regardless of this attribute.
poster—Static fallback/initial image URL. Omit it and the seed renders its own single-frame still.
speed1Clock multiplier, live-retunable. 0 freezes the clock at t0.
t00Initial clock time in seconds; also the still-frame time when posterized.
mouse—"x,y,z,w" — pins iMouse to a constant for drag-to-orbit kernels.
max-dpr1.5Devicepixelratio cap, clamped to [0.5, 2]. Embeds default lower than the main site (2) — it's decoration on someone else's page.
attributionhoverhover: chip fades in on hover/focus, or for 3s after a touch tap. always: persistent at 60% opacity. off: absent — Pillar 5 goodwill, no friction required.
integrity—"sha256-<b64>" of the resolved GLSL text. A mismatch refuses to compile — zero-backend content pinning for hosts that don't want to trust the garden origin to stay honest about what it serves.

Host CSP

Minimum policy for a garden-hosted embed (G = the garden origin the script/JSON are served from):

script-src  G;          # the seed module itself
connect-src G;          # <garden>/<id>.json
img-src     <your own poster image origins, if any>;

Not needed: worker-src (no workers), style-src additions (constructable stylesheets, with a per-shadow-root <style> fallback), unsafe-eval (never), any frame-src (no iframes — <shader-seed> is a custom element precisely so you don't pay iframe weight). Self-hosting the seed script and kernel JSON collapses everything to 'self'.

SRI (Subresource Integrity)

The floating URLs (seed@1.js, seed.js) receive fixes in place, so they can't carry a fixed integrity hash. Pin a specific release (seed@<x>.<y>.<z>.js) instead if you want to verify the bytes never change under you — check the box above. Every pinned release's hash lives in the machine-readable ledger this page reads: releases.json — one {version, file, sha384, bytes, date} entry per release, written by tools/bake_seed.py at mint time and re-verified against the actual file bytes on every subsequent bake, so the hash this page hands you can never silently drift from the file it describes.
